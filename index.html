Bienvenido a CotiStudio

Esta versión amplía el editor con elementos ilimitados, capas, arrastrar/redimensionar, cobertura de zonas, plantillas, páginas y exportación PDF.

  • El PDF importado se mantiene exactamente como fondo visual para conservar su texto, dibujos e imágenes.
  • Para sustituir un texto original, cubre primero su zona y coloca el nuevo texto encima.
  • El fondo original no se vuelve automáticamente editable como Word; reconstruirlo automáticamente requiere una etapa adicional de reconocimiento.
