PÁGINA
Documento original

Las páginas originales se muestran como imágenes de alta resolución para conservar sus dibujos. Puedes añadir textos y nuevas imágenes encima.

Esta primera versión todavía no separa automáticamente cada texto, precio o dibujo del PDF. El fondo original permanece intacto; los elementos añadidos sí se pueden editar.
