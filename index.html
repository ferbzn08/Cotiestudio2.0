CotiStudio

Diseño de cotizaciones · FireGroup

1 Añadir elementos

Selecciona un elemento en la página para moverlo. Usa el círculo naranja superior para rotarlo y el punto rojo inferior para cambiar su tamaño.

2 Plantillas

Las plantillas guardadas quedan en este navegador. Exporta un JSON para respaldarlas o moverlas a otro equipo.

3 Páginas

“Añadir PDF como páginas” incorpora todas las páginas de otro PDF al final del documento.

4 Configuración del sistema

Cambia la apariencia de CotiStudio sin alterar los colores de los elementos ya diseñados.

Área de diseño

Documento nuevo

Importa un PDF o crea una página.
Consejo: para diseños con diagonales, usa “Franja diagonal” y el control de rotación. Para poner tu logotipo, usa “Logo / imagen”.

A Propiedades

Selecciona un elemento en la página o en Capas para editarlo.

B Importar recursos

Los archivos PDF se procesan en tu navegador. Las librerías se cargan desde CDN; necesitas conexión a internet.

C Atajos

• Seleccionar: clic en el objeto o su capa.
• Mover: arrastrar el objeto.
• Rotar: arrastrar el círculo naranja.
• Redimensionar: arrastrar el punto rojo inferior derecho.
• Eliminar: selecciona y pulsa Eliminar.
• Ctrl/Cmd + Z: deshacer.
