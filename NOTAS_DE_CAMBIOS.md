# Notas de cambios

1. Se eliminó la reconstrucción automática del texto extraído del PDF, porque generaba capas duplicadas que se veían superpuestas con el texto original.
2. Se añadió la herramienta Franja, que empieza en x=0, ancho=100% y altura=7%, en azul marino; es una forma editable.
3. Se mantuvo el PDF como fondo visual para priorizar la fidelidad de la cotización y sus dibujos.
4. Se ajustaron instrucciones y controles móviles.

Limitación: el fondo del PDF sigue siendo una imagen de página; esta revisión no convierte su texto o imágenes en objetos independientes.
